# Installation

PrivX MCP Server is a single binary configured with a TOML file, environment variables, or both. That makes it easy to run almost anywhere: as a plain process, a `systemd` service, a container, or a Kubernetes workload. There is no recommended deployment method; choose whatever fits your environment and operational practices.

## Where to go next

- **Production deployment**: see [Deployment](../../deploy/README.md) for the available deployment options and examples.
- **Try it out**: use the [Local Docker demo](../../deploy/docker/demo/README.md), which bundles a Keycloak login flow.
- **Development setup**: see [Development](../development/DEVELOPMENT.md) for building from source and running locally.

Whichever route you take, fill in the required settings as described in [Configure the server](03-configure.md).
